# webcmd-plugin-crates

Webcmd commands for crates.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/plugins/crates
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd crates crate` | Single crates.io crate metadata (latest version, downloads, license, repo) |
| `webcmd crates search` | Search the public crates.io registry by keyword |
